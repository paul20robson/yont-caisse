# YONT Caisse

Application de caisse de YONT HOTELLERIE SARL (restaurant Sainte Anastasie et centre de formation, Dschang).

- `public/` : l'application telle qu'elle est mise en ligne.
- `wrangler.jsonc` : réglages Cloudflare (Worker « caisse »).

Chaque modification envoyée sur la branche `main` est mise en ligne automatiquement par Cloudflare sur https://caisse.yorsa.workers.dev

Mise en ligne automatique activée le 1er novembre 2026.
